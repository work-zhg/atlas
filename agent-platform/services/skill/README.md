# atlas-skill

技能应用：技能包的上传、扫描、审查、发布与下架，技能市场；智能体引用这里发布的技能。

## 用户中心登记

代码里只有判断用到的编码（`atlas_skill/auth.py`），不往用户中心登记。下面这些由运营人员在运营中心
「应用目录」里录入；编码必须和这里一致，名称、角色怎么组合可以按需调整。

**应用**

| 编码 | 名称 | 说明 |
|---|---|---|
| `skill` | 技能 | 技能包的上传、扫描、审查、发布与下架；智能体引用这里发布的技能 |

应用编码由配置 `ATLAS_SKILL_UC_APP_CODE` 决定（默认 `skill`），调用户中心开放接口时请求头 `X-Caller-App` 写它。

**操作码**

| 模块 | 编码 | 名称 |
|---|---|---|
| 技能 | `skill:upload` | 上传技能 |
| 技能 | `skill:review` | 审核技能（审查、停用、下架、重新检查） |
| 系统 | `audit:view` | 查看审计 |

**建议的内置角色**

| 编码 | 名称 | 操作码 |
|---|---|---|
| `SKILL_AUTHOR` | 技能作者 | `skill:upload`（含脚本或非内置来源的技能要经审核才发布） |
| `SKILL_ADMIN` | 技能管理员 | `skill:upload`、`skill:review`、`audit:view` |
