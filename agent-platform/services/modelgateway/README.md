# atlas-modelgateway

模型平台：管理平台（登记模型、账号、Key、调用记录）和模型网关（按 Key 把调用转发给供应商）。

## 用户中心登记

代码里只有判断用到的编码（`atlas_modelgateway/auth.py`、`perms.py`），不往用户中心登记。下面这些由
运营人员在运营中心「应用目录」里录入；编码必须和这里一致，名称、角色怎么组合可以按需调整。

**应用**

| 编码 | 名称 | 说明 |
|---|---|---|
| `model-gateway` | 模型管理 | 登记模型、私有模型授权、API Key |

应用编码由配置 `ATLAS_MODELGW_UC_APP_CODE` 决定（默认 `model-gateway`）。

**操作码**

| 模块 | 编码 | 名称 |
|---|---|---|
| 模型 | `model:manage` | 登记、修改、删除模型；私有模型授权；客户端 Key |

**数据编码**

| 编码 | 名称 | 说明 |
|---|---|---|
| `Model` | 模型 | 一个模型一条：只读 = 使用（私有模型能选进自己的用户 Key）；Owner = 所有者 |

**建议的内置角色**

| 编码 | 名称 | 操作码 |
|---|---|---|
| `MODEL_ADMIN` | 模型管理员 | `model:manage` |

模型管理员还要在租户的用户中心里拿到数据权限「全部模型 · 所有者」，才能使用、分配全部模型。
