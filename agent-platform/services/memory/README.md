# atlas-memory

记忆服务：按作用域隔离的主题与条目存储（Atlas 的跨会话记忆存在这里）。

## 用户中心登记

本服务不往用户中心登记任何东西。下面这些由运营人员在运营中心「应用目录」里录入；编码必须和这里一致。

**应用**

| 编码 | 名称 | 说明 |
|---|---|---|
| `memory` | 记忆服务 | 按作用域隔离的主题与条目存储（Atlas 的跨会话记忆存在这里） |

应用编码由配置 `ATLAS_MEMORY_UC_APP_CODE` 决定（默认 `memory`）。没有操作码：作用域的定义是产品自带的，
由运营中心经运营接口维护。

**数据编码**：每个打开了数据权限开关（`check_permission`）的作用域一个，编码是作用域的 `data_code`
（不填时按作用域编码生成，如 `user` → `MemoryUser`）。

| 编码 | 名称 | 说明 |
|---|---|---|
| `MemoryUser` | 记忆 · 用户 | 一个作用域实例一条：只读（列目录、加载）/ 读写（写入、拆分、撤销）/ Owner（彻底删除） |

以后新打开开关的作用域，也要把它的数据编码录进来，否则校验数据权限时用户中心会说编码不存在。
