# 星河科技信息安全规范

## 一、账号与密码

### 1.1 密码规则

办公系统密码长度不少于 12 位，须同时包含大写字母、小写字母、数字和特殊字符中的三类。密码每 90 天必须更换一次，且不得与最近 5 次使用过的密码相同。

### 1.2 多因素认证

访问代码仓库、生产服务器和财务系统必须开启多因素认证，可使用公司统一发放的硬件令牌或企业微信动态口令。

## 二、远程访问

员工在公司网络以外访问内部系统，必须通过公司 VPN 接入。禁止使用个人搭建的代理或内网穿透工具；VPN 账号仅限本人使用，不得转借他人。

## 三、数据分级

| 级别 | 示例 | 处理要求 |
| --- | --- | --- |
| 公开 | 官网内容、已发布的新闻稿 | 无特殊要求 |
| 内部 | 组织架构、内部制度 | 仅限公司内部传播 |
| 机密 | 客户名单、财务报表、源代码 | 加密存储，按需授权，禁止外发 |
| 绝密 | 未公开的融资与并购信息 | 仅限指定人员，访问留痕并定期审计 |

机密及以上级别数据禁止上传至任何外部网盘或公共大模型服务。

## 四、设备管理

办公电脑须安装公司统一的终端安全软件并开启全盘加密。设备丢失须在 2 小时内报告 IT 服务台，由 IT 远程锁定并擦除数据。

## 五、安全事件上报

发现疑似钓鱼邮件、病毒感染或数据泄露时，应立即断开网络并通过 IT 服务台热线 8000 上报，不得自行删除相关证据。
